# 《恒温牢饭》

> 像素叙事料理 / 监狱群像 / 线索推理 · Godot 4.7.2 可试玩 Demo

在灰烬监狱，饭菜不是慰藉，而是一种审讯方式。

玩家扮演入狱厨师 **林烬**。五天内，你要在有限食材中决定做什么、做给谁吃，并在五名囚犯的饭后反应、只言片语和残缺档案之间，找回父亲林诚失踪的线索。你可以让所有人吃饱，也可以把一碗特供送到最需要开口的人面前；每一次善意、试探或敷衍，都会改变他们对你、对监狱，以及对真相的态度。

## 故事

灰烬监狱对外宣称实行“恒温配餐”：犯人可以得到定制餐食，监区据此维持秩序。林烬却发现，每一份餐都被记录，每一次情绪波动都被归档；这套看似温和的制度，正在精准地标记每个人的软肋。

林烬的父亲林诚曾在这座监狱工作，后在一次档案清洗后失踪。厨房、牢房走廊和食堂成了仅有的调查现场：一碗温热的米羹可能换来一句证词，一份不合口味的餐也可能让整条线索断掉。

## 核心体验

### 1. 做饭不是配方题

每天会提供有限食材。玩家从食材、做法和摆盘中组合料理：食材本身带有“温柔”“刺激”“朴素”“恐惧”等标签，做法和摆盘会继续改变标签含义。不同囚犯有不同的偏好、厌恶与心理阈值。

- **大锅**：送给全体囚犯，优先维持整体满意度。
- **小碗特供**：只送给一人，能更强地推进个人关系，但其他人会感到被怠慢。
- **特殊料理**：特定组合会触发专属饭后反应和剧情入口。
- **失败也有后果**：不合口味、羞辱性摆盘或错误选择会改变关系，不会被系统悄悄抹掉。

### 2. 五名囚犯，五条互相咬合的线

| 囚犯 | 表面身份 | 线索方向 |
| --- | --- | --- |
| 苏晚 | 替人顶罪、沉默寡言的年轻囚犯 | 顶罪案与亲人 |
| 老屠 | 被所有人忌惮的“屠夫” | 灭口名单与监区暴力 |
| 白术 | 因非法行医入狱的前医生 | 化验报告与药物 |
| 阿萤 | 被指控纵火毁档的少女 | 被篡改的原件与记忆 |
| 钟队长 | 入狱的前狱警 | 押送记录与“归零”制度 |

这些并不是五个互不相干的支线。白术的化验可能唤回阿萤的记忆；阿萤的原件又会让钟队长愿意作证；最终的证词会改变苏晚是否开口。料理、对话、线索和角色关系共同构成一张网。

### 3. 在场景里行动，而不是只点菜单

试玩版把每日流程拆成三个可自由移动的房间：

```text
厨房做饭 → 牢房走廊送饭与对话 → 食堂调查、反馈与收工
```

- **厨房**：走到灶台制作料理；完成一餐后，出口才会开放。
- **牢房走廊**：逐个走到牢窗前送饭、触发对话。大锅要送给所有目标，小碗只送给指定囚犯。
- **食堂**：除了结算，还可调查公告栏、配餐台账、餐桌余物、旧案归档车和墙面案件板，理解监狱背景并整理已经取得的信息。

## 当前试玩内容

### 已实现

- `WASD` 控制林烬移动，`E` 与灶台、出口、牢窗和调查物互动。
- 清晰的新手引导：画面底部持续显示当前场景、目标与下一步操作。
- 三段式出入口流程：未完成当前目标时，下一个场景不会开放。
- 料理组合、口味匹配、即时反馈、长期满意度、信任/恐惧/愤怒/愧疚/疑心等状态。
- 囚犯档案室：官方记录、人物观察、料理偏好、实时心理状态和个人线索进度。
- 墙面案件板：监狱背景、真相关键链、线索网络与已取得线索的详情。
- 正式内容数据：5 天、5 名囚犯、9 种食材、4 种做法、4 种摆盘、特殊料理、交叉事件与 5 个结局判定。
- 规则、场景路线、调查交互和内容导出测试。

## 如何运行

1. 安装 [Godot 4.7.2](https://godotengine.org/download/archive/4.7.2-stable/)。
2. 克隆本仓库，进入 `222` 文件夹。
3. 在 Godot 中导入 `project.godot`，按 `F6` 或 `F5` 运行。

也可以在终端运行：

```powershell
godot --path . --editor
```

主场景为 `scenes/Main.tscn`。首次打开时 Godot 会自动生成 `.godot` 缓存；该缓存不需要提交到 Git。

## 测试

工程自带规则、流程、世界节点、调查交互与清理检查。确保 Godot 可从命令行使用后，在 `222` 目录运行：

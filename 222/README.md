# 《恒温牢饭》试玩 Demo

这是以 `F:\game\111` 的《恒温牢饭》策划、角色和剧情规则为准制作的 Godot 试玩版。`222` 只提供 Godot 技术底座与本地像素素材。

## 故事背景

玩家扮演被关进灰烬监狱的厨师林烬。五天内，你要用料理让苏晚、老屠、白术、阿萤和钟队长愿意开口，逐步拼出监狱里的真相。

## 每日流程

```text
厨房做饭 → 牢房走廊送饭与对话 → 食堂查看反馈并收工
```

1. 在厨房走到灶台旁按 `E`，选择食材、做法和摆盘，把料理装入餐箱。
2. 走到右侧“牢房走廊出口”按 `E`。出口只会在完成一餐后开放。
3. 在走廊逐个走到牢窗前按 `E` 送饭、对话。大锅必须送给五人；小碗只送给指定囚犯。
4. 所有目标送完，右侧食堂出口开放。进入食堂后走到中央收工出口按 `E`，查看反馈并进入下一天。

食堂不是只用来结算：公告栏说明“恒温配餐”制度，配餐台账记录当天送餐，餐桌余物提示囚犯反应，旧案归档车连向人物档案，墙面案件板把已获线索与真相条件串联起来。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动林烬 | `WASD` |
| 靠近目标后互动 | `E` |
| 查看囚犯关系和线索 | 左侧“囚犯档案”“案件板” |

囚犯档案分为官方记录与料理/线索分析两页，显示牢号、罪名、观察记录、口味偏好、实时心理指标和个人线索进度；不会提前泄露尚未获得的真相。

游戏画面底部会持续显示当前目标和操作提示。

## 运行

用 Godot `4.7.2` 打开 `F:\game\222`，按 `F6` 或 `F5` 启动。主场景是 `scenes/Main.tscn`。

## 当前内容

- 5 天、5 名囚犯、料理搭配、关系数值、线索和 5 个结局均读取自 `data/hengwen_content.json`。
- 本地厨房、牢房走廊和食堂背景分别对应可移动、可交互的三个游戏房间。
- `tests/` 包含剧情规则、日流程和三场景出口流程检查。

## 工程结构

```text
scenes/Main.tscn        游戏入口
scripts/HengwenMain.gd  场景、UI 与交互
scripts/hengwen/        料理、剧情、线索、状态规则
data/                   《恒温牢饭》正式内容数据
assets/                 保留的本地像素素材库
tests/                  可回归的玩法测试
```
